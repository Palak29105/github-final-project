# Simple Interest Calculator

## Project Description

This project is a simple interest calculator written in Bash.

The calculator takes the following inputs from the user:

- Principal amount
- Rate of interest
- Time period

It then calculates the simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Accepts principal amount from the user
- Accepts rate of interest from the user
- Accepts time period from the user
- Calculates simple interest
- Displays the calculated result

## How to Run

Run the Bash script using:

bash simple-interest.sh

## Formula

SI = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period
